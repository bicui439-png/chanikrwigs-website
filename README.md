# chanikrwigs.com

Website of Chani Kramer Wigs Salon, 1474 60th St, Brooklyn NY.

- Hosted on Netlify (project "chanikrwigs", account chani@chanikrwigs.com). Netlify publishes the `public/` folder.
- Pages are generated by `build.py` (shared header/footer). After editing it run `python3 build.py`, which rewrites `public/*.html`.
- Forms (contact, booking-request) are Netlify Forms; `public/__forms.html` registers their fields. Submissions are emailed to chani@chanikrwigs.com.
- `public/_redirects` keeps old WordPress addresses working. `/privacy-policy-2/` and `/terms-conditions/` must stay: the 10DLC texting registration points to them.
- Booking currently sends a request; see `public/js/book.js` (`getAvailability`, `createBooking`) for where the salon system API will plug in.
