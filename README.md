# chanikrwigs.com

Website of Chani Kramer Wigs Salon, 1474 60th St, Brooklyn NY.

- Hosted on Netlify (project "chanikrwigs", account chani@chanikrwigs.com). Netlify publishes the `docs/` folder (GitHub Pages; Netlify was the first host).
- Pages are generated by `build.py` (shared header/footer). After editing it run `python3 build.py`, which rewrites `docs/*.html`.
- Forms (contact, booking-request) send through Web3Forms (key in `docs/js/site.js` → `SITE.formKey`, account chani@chanikrwigs.com); messages are emailed to chani@chanikrwigs.com. Without a key they fall back to Netlify Forms (`docs/__forms.html`).
- Old WordPress addresses: GitHub Pages has no redirects file, so `build.py` writes folder pages (`docs/privacy-policy-2/`, `docs/terms-conditions/`, `docs/about/`, ...). `/privacy-policy-2/` and `/terms-conditions/` must stay: the 10DLC texting registration points to them. `docs/CNAME` holds the domain.
- Booking currently sends a request; see `docs/js/book.js` (`getAvailability`, `createBooking`) for where the salon system API will plug in.
